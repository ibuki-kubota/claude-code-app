プライバシーポリシー

個人用ツール「Claude Code」（以下「本ツール」）での、Google のデータの扱いを定めます。

This policy explains how the personal tool "Claude Code" handles Google user data.

1. 使うデータ

  • YouTube（読み取りのみ）：運営者本人のチャンネルと動画の統計・アナリティクス（収益の数字を含む）。
    YouTube (read-only): statistics and analytics of the owner's own channel and videos, including revenue figures.
  • Google ドライブ：本ツールが自分で作ったファイルだけ（振り返り用の表と画像）。ほかのファイルは読みません。
    Google Drive: only the files this tool creates itself (a review spreadsheet and its images). No other files are read.

2. 使い方

運営者本人のパソコンの中で、自分のチャンネルの振り返りと分析にだけ使います。

The data is used only on the owner's computer, to review and analyse the owner's own channel.

3. 第三者への提供

第三者に渡したり、売ったり、広告に使ったりしません。本ツールによる Google API から受け取った情報の使用と移転は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

The data is never shared, sold or used for advertising. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 保存と削除

ログイン情報と読み取ったデータは、運営者本人のパソコンと Google ドライブにだけ保存し、不要になったら削除します。

Sign-in data and the data read are stored only on the owner's computer and Google Drive, and are deleted when no longer needed.

5. 許可の取り消し

許可は、Google アカウントの「サードパーティのアプリとサービス」からいつでも取り消せます。

Access can be revoked at any time from "Third-party apps & services" in the Google Account.
